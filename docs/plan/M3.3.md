# M3.3 — `c` peels columns one by one, `ctrl+t` shortens the time, `R` resets the display  (status: done)

## Problem
On the logs screen `c` cycles the **time format** (local → UTC → relative → hidden). The relative format is shorter, so the first presses look like the time column "shrinks", but `c` never touches the other columns. Getting more room for the message today means opening the `C` picker or pressing `z`, and getting back to the default layout also goes through the picker (`C` then `r`).

## 1. `c`: hide one more column per press, then bring them all back
Each press hides the next column, in a fixed order. After the last one, the next press shows them all again:

| Press | Hidden | Line (160 cols, demo) |
|---|---|---|
| — | nothing | `m8q7v 19:14:02.113  INFO [http-nio-8080-exec-3] c.a.p.PaymentController : payment accepted id=…` |
| 1 | time | `m8q7v  INFO [http-nio-8080-exec-3] c.a.p.PaymentController : payment accepted id=…` |
| 2 | + level | `m8q7v [http-nio-8080-exec-3] c.a.p.PaymentController : payment accepted id=…` |
| 3 | + thread | `m8q7v c.a.p.PaymentController : payment accepted id=…` |
| 4 | + class (logger) | `m8q7v payment accepted id=…` |
| 5 | all four back | the line as it was before press 1 |

Rules:
- **Every press changes something.** Columns that are already hidden are skipped: by automatic narrowing (thread below 140 cells, class below 110), by `C`, or by config. At 100 columns (thread and class already hidden) the cycle is time → level → back.
- **Press 5 restores the layout from before press 1**, not the defaults. Columns hidden before the cycle stay hidden.
- **The pod column is not part of the cycle.** `I` keeps cycling it (short → full → hidden) because it tells which replica wrote the line.
- **Changing the columns another way ends the cycle**: `C`, `z`, `I` or `R`. The next `c` starts again from the current layout.
- **No information is lost when the level is hidden.** ERROR messages are already red. WARN messages will be drawn in the warning color **only while the level column is hidden**. The level filters (`l e w a`) and zoom are unchanged.
- **Flash text** says what the press did: `time hidden`, `level hidden`, `thread hidden`, `class hidden`, `columns restored`. The status bar keeps listing the shown columns when they differ from the default, as it does now.
- The cycle order is fixed in code (time, level, thread, class), in one list in `columns.go`. It is not made configurable for now: nobody has asked for that.

## 2. `ctrl+t`: shorten the time, never hide it
The time format keeps its own direct key, moved from `c` to **`ctrl+t`**. It cycles **local → UTC → relative → local**. The "hidden" step is gone because hiding is now the job of `c`.

| Press | Time column |
|---|---|
| — | `19:14:02.113` (local) |
| 1 | `17:14:02.113` (UTC) |
| 2 | `3m ago` (relative, the shortest) |
| 3 | `19:14:02.113` (local again) |

- If `c` has hidden the time, `ctrl+t` shows it again in the next format and ends the `c` cycle. The key always has a visible effect.
- The `C` picker shows the current format next to `t` and can also change it with `f`, so the picker stays complete.
- The key can be remapped with `ui.keymap.timestamps`. There is no start-up format setting; logs open in local time.
- Help, the key bar and the README follow the action table as usual. `c` is described as "hide the next column (time, level, thread, class), then show them again", and `ctrl+t` as "time format: local, UTC, relative".

## 3. `R`: reset the display, without opening the picker
`R` sets the **display** of the logs screen back to its defaults in one key:
- columns: automatic narrowing again (no manual choice), pod id short, time format local, and the configured `ui.logs.columns` when set;
- focus layout (`z`) off and the `c` cycle ended;
- horizontal pan back to 0;
- wrap back to the configured default.

It **does not touch what is shown**: filters, levels, time window, follow/pause, pod scope, sort order and the selected line stay the same. `R` changes how lines look, never which lines appear. Flash: `display reset`.

Why `R`: it is free on the logs screen, it is `r` of the picker (`C` then `r` resets the columns today), it is reachable without AltGr on QWERTY, AZERTY and QWERTZ, and `r` stays "resync" everywhere. On the services screen `R` stays unbound.

## 4. Keymap and configuration
- Two new actions: `columns_cycle` (`c`) and `reset_display` (`R`).
- `timestamps` moves from `c` to `ctrl+t`. `ctrl+t` is free on every screen and reaches the program in all common terminals.
- Key bar: the compact bar shows `c cols`; the full bar also shows `ctrl+t time` and `R reset`.

## 5. Tests
- The cycle at 160, 120 and 100 columns: which columns each press hides, skipped columns, and press N+1 restoring the layout from before the cycle.
- The cycle interacting with `C`, `z` and `I`: each one ends the cycle.
- Level hidden: WARN messages get the warning color, and the level filter still works.
- `R` after `c`, `z`, `C`, `I`, pan and wrap: the display is back to its defaults, and filters, window, scope and the selected line are unchanged.
- `ctrl+t` cycles local → UTC → relative without ever hiding the time; after `c` has hidden the time, it shows it again and ends the cycle. Picker `f` does the same cycle.
- Goldens for press 2 and press 4 at 160×30; key bar and help goldens updated.

## 6. Decision to record (D-029)
`c` peels the columns in the order time, level, thread, class, then restores them. The time format moves to `ctrl+t` and never hides the time. `R` resets the display, never the data. WARN messages are coloured while the level column is hidden.
